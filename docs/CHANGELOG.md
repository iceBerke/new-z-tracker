# Patch history

Every patch to the ZTracker Fiji plugin, newest first. This lived in `README.md` until p10.18,
by which point 67 rows were 57% of that file by word count and buried everything a user actually
needs behind a wall of history.

> **These rows are a record, not documentation — never edit one.** A row states what was
> understood and decided *at the time it was written*, and that is exactly what makes it useful
> later. Some rows are therefore knowingly out of date, on purpose: several give the projection
> tool's streaming peak as 12 bytes per pixel where the true figure is 13 (corrected in p10.17,
> which says so in its own row), and some name classes or file locations that have since moved.
> Leave them. When something changes, **add a new row saying so** — never revise an old one,
> because a changelog that is quietly kept current is no longer evidence of anything.

> **Note on tool numbers:** since **p9.1**, tools are numbered in **pipeline order** — Tool 1 = Z-Projection generator, Tool 2 = indexed 3D Z-extractor, Tool 3 = TopoJ / direct-Z extractor. Entries below from **before p9.1** used creation order (Tool 1 = extractor, Tool 2 = generator), so a "Tool N" in an older entry refers to the numbering as it stood then.
